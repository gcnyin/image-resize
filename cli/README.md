# imgcompr — 命令行图片压缩

image-resize 的命令行模块，**只做压缩**（无裁剪、无缩放），Go 标准库实现、零第三方依赖、单二进制。

## 用法

```sh
go build -o imgcompr .
./imgcompr [-o 输出目录(默认原目录)] 文件1 [文件2 ...]
```

- 输出：`-o` 目录下用原文件名；默认写到原目录、加 `_min` 后缀（`photo.jpg` → `photo_min.jpg`），**永不覆盖源文件**；输出已存在则直接覆盖（重跑幂等）。
- 退出码：全部成功 `0`；有跳过或失败 `1`；无参数 `2`。
- 支持格式：JPEG / PNG。WebP / HEIF 等打印 `跳过` 并继续（Go 标准库无 WebP 编码器）。

## 恒定压缩率（与三端一致）

目标字节数 = `max(4096, 源文件字节数)`（CLI 不缩放，输出像素 == 源像素，故目标即源大小）。

- JPEG：质量区间 `[40, 97]`，二分搜"不超过目标字节数的最大质量"；全区间超目标仍以 40 写出。
- PNG：无损直通重编码，无质量参数；已高度优化的源可能标注 `未变小`，属正常。
- 源文件小于 4096 字节时目标抬到 4096，输出允许比源大。

## 已知限制

- 不处理 EXIF 方向：`image/jpeg` 解码即丢弃 EXIF，orientation ≠ 1 的照片重编码后以像素方向为准。
- 动图（Animated WebP / GIF）不支持。
