# 图片工具 · CLI

返回仓库总览：[../README.md](../README.md)

image-resize 的跨平台命令行版（`imgresize`），基于 Go 标准库实现，零第三方依赖，**不做裁剪、只做缩放**。

## 构建

```sh
cd cli
go build -o imgresize .
```

## 用法

```sh
./imgresize (-p 1~100 | -max 像素) [-o 输出目录(默认原目录)] 文件1 [文件2 ...]
```

- `-p` / `--percent`：按百分比缩放，取值 `1~100`（如 `-p 50` 将宽高各缩为一半）。
- `-max` / `--max`：按最长边上限缩放，保持纵横比且不放大（如 `-max 1920`）。`-p` 与 `-max` 互斥，必须二选一。
- `-o` / `--output`：输出目录。指定不同目录时保持原文件名；写回原目录时自动加 `_50pct` 或 `_max1920` 后缀，**不覆盖源文件**。
- `-h` / `--help`：打印用法并退出。

写入过程先写临时文件再原子重命名，重复执行同一命令直接覆盖目标输出。

## 退出码

- `0`：全部文件处理成功。
- `1`：部分或全部文件跳过（如 WebP / HEIF / 未知格式）或失败（空文件、损坏、无法解码）。
- `2`：参数错误（缺少缩放参数、参数越界、未传入文件等）。

## 算法对齐

与 `android/`、`windows/`、`macos/` 三端一致：

- **格式嗅探**：按文件头魔数识别 JPEG / PNG / WebP / HEIF，魔数未知时按扩展名兜底；CLI 仅编码 JPEG 与 PNG，遇到 WebP / HEIF 时跳过并提示格式名称。
- **EXIF 摆正**：解析 JPEG APP1 TIFF IFD0 的方向标记（支持 1~8 全部方向），先摆正再缩放。
- **逐级 1/2 双线性下采样**：循环将宽高按 `1/2` 降采样，直到再减半会低于目标尺寸，再对预乘 RGBA 像素做一次精确到目标尺寸的双线性插值，目标边长使用四舍五入且 `.5` 靠偶数（至少 1px）。
- **恒定压缩率编码**：`targetBytes = max(4096, 源文件字节数 × 输出像素 / 源像素)`。JPEG 在质量 `[40, 97]` 内二分搜索不超过 `targetBytes` 的最高质量；PNG 无损直通编码。
- **无默认 4096px 工作区上限**：命令行批处理默认按源图全尺寸缩放；如需限制最长边，请传入 `-max 4096`。
